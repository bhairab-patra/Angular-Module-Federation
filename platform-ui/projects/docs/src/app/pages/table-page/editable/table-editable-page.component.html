Inline Row Editing

Click the pencil icon to enter edit mode — all cells become inputs. Click the checkmark to save or X to cancel. Only one row can be in edit mode at a time. With [confirmDelete]="true", clicking the trash icon shows a built-in confirm dialog before deleting. Set editable: false on a column to keep it read-only while editing — below, Department stays plain text even in edit mode, while every other column becomes an input.

Every feature here is independently switchable: sortable is set per column (click Name, Department, Role, or Salary to sort), [pagination] + [pageSize] page the rows, [stickyHeader] pins the header, and required/minLength/pattern on a column enforce inline validation (with an error message) before Save is allowed. A toast confirms every save/delete — disable it with [showToast]="false". Truncated header or cell text shows a tooltip on hover.

Form Dialog — Add & Edit

pui-lib-form-dialog is a reusable modal with fully configurable [fields]. Set [data] to pre-fill values for an edit flow; leave empty for an add flow. Use size="sm|md|lg" to control the dialog width.

pui-lib-editable-table is a Web Component. Array/object inputs (columns, data) must be set as JS properties from React/HTML; Angular uses property binding directly.
