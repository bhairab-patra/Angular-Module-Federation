Inline Row Editing

Click the pencil icon to enter edit mode: every cell becomes an input. Click the checkmark to save, or X to cancel. Only one row can be in edit mode at a time. With [confirmDelete]="true", clicking the trash icon opens a built-in confirm dialog before deleting. Set editable: false on a column to keep it read-only while editing. Below, Department stays plain text even in edit mode, while every other column becomes an input.

Every feature here can be switched on or off independently. Set sortable on a column to enable sorting (try Name, Department, Role, or Salary). Add [pagination] and [pageSize] to page the rows, and [stickyHeader] to pin the header. Add required, minLength, or pattern to a column to enforce inline validation, with an error message, before Save is allowed. A toast confirms every save or delete by default; disable it with [showToast]="false". Truncated header or cell text shows a tooltip on hover. The built-in Edit and Delete buttons toggle independently with [showEditAction] and [showDeleteAction], so you can build an edit-only or delete-only row toolbar. Use [rowActions] to add custom buttons alongside them, like the "View" button here.
