Minimal — Plain Display

The simplest usage — just pass [columns] and [data]. No toolbar, no sorting, no extras.

Sticky Header — Search & Sort

Enable [searchable], [sortable], and [stickyHeader]. Set [maxHeight] to constrain scroll.

Badge Cells & Loading State

Use type: 'badge' with a badgeMap to colour-code status values. Toggle the [loading] input to show the shimmer skeleton.

Action Menu — 3-dot Dropdown per Row

Action menus are part of pui-lib-data-table. Pass an [actions] array — each item has a label, an action(row) callback, and an optional disabled(row) predicate. The "Remove Employee" action is disabled for Inactive rows.

Framework Usage

pui-lib-table is a Web Component — works in Angular, React, and plain HTML. The columns, data, and actions arrays must be passed as JS properties from React / HTML; Angular uses property binding directly.

Pass typed [columns], [data], and [actions] arrays directly. All boolean flags use property binding.
Set columns, data, and actions as JS properties via ref. Listen to events with addEventListener.
Load pui-elements.js once. Assign array inputs as JS properties.
