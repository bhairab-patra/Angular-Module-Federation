Manual Mode

With triggerMode="manual", the popover ignores its own trigger's click/hover — you decide when it opens and closes from your own component logic.

Opened programmatically — the dot itself does nothing on click.

Framework Usage

pui-lib-popover is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. Project the trigger element with a popoverTrigger attribute; everything else projected becomes the panel body.
