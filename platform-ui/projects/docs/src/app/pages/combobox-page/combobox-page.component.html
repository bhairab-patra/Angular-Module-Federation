Framework Usage

pui-lib-combobox is a standalone Web Component with smart JSON-parse setters — pass arrays from Angular with [options] bindings, from React via ref, and from HTML via JS property assignment.

Import PuiComboboxComponent into your component's imports array.
import { PuiComboboxComponent, ComboboxOption } from '@bhairab-patra/platform-ui';

@Component({
  imports: [PuiComboboxComponent],
  template: `
    <pui-lib-combobox
      [options]="options"
      [value]="selected"
      placeholder="Search…"
      [allowFreeText]="true"
      (valueChange)="selected = $event">
    </pui-lib-combobox>
  `
})
export class MyComponent {
  options: ComboboxOption[] = [
    { value: 'a', label: 'Alpha', description: 'First letter' },
    { value: 'b', label: 'Beta',  group: 'Greek' },
  ];
  selected: string | number | null = null;
}
Assign the options array via a ref in useEffect — HTML attributes only accept strings.
import { useRef, useEffect, useState } from 'react';
import '@bhairab-patra/platform-ui';

function MyComponent() {
  const ref = useRef(null);
  const [value, setValue] = useState(null);

  useEffect(() => {
    if (ref.current) {
      ref.current.options = [
        { value: 'ng', label: 'Angular' },
        { value: 'rx', label: 'React' },
      ];
    }
  }, []);

  return (
    <pui-lib-combobox
      ref={ref}
      placeholder="Select framework…"
      onValueChange={e => setValue(e.detail)}
    />
  );
}
Set el.options as a JS property after customElements.whenDefined.
<pui-lib-combobox id="cb" placeholder="Select…" allow-free-text clearable></pui-lib-combobox>

<script>
customElements.whenDefined('pui-lib-combobox').then(() => {
  const el = document.getElementById('cb');
  el.options = [
    { value: 'ng', label: 'Angular', group: 'Frontend' },
    { value: 'rx', label: 'React',   group: 'Frontend' },
    { value: 'nj', label: 'Node.js', group: 'Backend'  },
  ];
  el.addEventListener('valueChange', e => console.log(e.detail));
});
</script>
