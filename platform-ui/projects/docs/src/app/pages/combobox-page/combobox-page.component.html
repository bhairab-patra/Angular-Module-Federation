Framework Usage

pui-lib-combobox is a standalone Web Component with smart JSON-parse setters — pass arrays from Angular with [options] bindings, from React via ref, and from HTML via JS property assignment. It also implements ControlValueAccessor, so in Angular you can bind it with formControlName instead of manual [value]/(valueChange).
