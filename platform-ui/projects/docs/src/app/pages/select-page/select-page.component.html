Basic Usage

Pass an options array with an optional icon field (emoji, flag, or SVG). The icon appears in the trigger and in each dropdown row.

Searchable Dropdown

Add [searchable]="true" to show a filter input at the top of the popup. Useful for long option lists. Customize the input placeholder with searchPlaceholder.

Sizes

Three size variants — sm, md (default), and lg — to match your form density needs.

Small sm
Medium md
Large lg

Validation States

Pass error for a red error message, hint for helper text, [required]="true" for an asterisk indicator, and [disabled]="true" to make the field non-interactive.

Disabled Options

Set disabled: true on individual items in the options array to make them non-selectable and visually dimmed.

Selected plan: {{ vTier || '—' }}

Framework Usage

pui-lib-select is a Web Component. Pass options via Angular's [options] binding, or as a JS array property from React and HTML. All string props work as attributes.
