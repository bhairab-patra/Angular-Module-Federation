Framework Usage

pui-badge uses ng-content — put the label text between the tags. The variant and size attributes behave identically in all frameworks.

Import BadgeComponent into your component's imports array.
import { BadgeComponent } from '@solifi/platform-ui';

@Component({
  imports: [BadgeComponent],
  template: `
    <pui-badge variant="success">Active</pui-badge>
    <pui-badge variant="warning" size="sm">Pending</pui-badge>
    <pui-badge variant="danger">Error</pui-badge>
    <pui-badge [variant]="statusVariant">Dynamic</pui-badge>
  `
})
export class MyComponent {
  statusVariant = 'info';
}
No ref or event wiring needed — just render the element with attributes.
import '@solifi/platform-ui';

function StatusBadge({ status }) {
  const variantMap = {
    active:   'success',
    pending:  'warning',
    error:    'danger',
    info:     'info',
  };
  return (
    <pui-badge variant={variantMap[status] ?? 'default'} size="sm">
      {status}
    </pui-badge>
  );
}
All props are plain HTML attributes. The label is the element's text content.
<pui-badge variant="success">Active</pui-badge>

<pui-badge variant="info">Informational</pui-badge>
<pui-badge variant="primary">New</pui-badge>
<pui-badge variant="default">Draft</pui-badge>
