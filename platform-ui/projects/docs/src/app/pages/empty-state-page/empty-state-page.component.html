Common Scenarios

The same component covers "no data yet", "no search results", and error states — just swap the icon, title, and description.

Sizes

sm fits inside a card or table body; lg suits a full empty page.

Framework Usage

pui-lib-empty-state is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. All inputs are plain strings, so they work as regular HTML attributes in every framework.
