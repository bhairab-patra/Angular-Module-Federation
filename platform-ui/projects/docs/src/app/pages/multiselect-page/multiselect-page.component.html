Chip Limit & Badge Count

When more items are selected than maxChips, a single count badge replaces individual chips.

Disabled Options & Disabled State

Individual options can be disabled via their disabled flag. The entire component can be disabled too.

Validation States

Pass error for a validation message (red border + text) or hint for helper text.

Framework Usage

pui-lib-multiselect is a standalone Web Component — the same element tag works in Angular, React, and plain HTML. The options and value inputs accept typed arrays (Angular binding) or JSON strings (HTML attribute).

Import PuiMultiSelectComponent into your component's imports array.
// component.ts
import { PuiMultiSelectComponent, MultiSelectOption } from '@bhairab-patra/platform-ui';

@Component({
  imports: [PuiMultiSelectComponent],
  template: `
    <pui-lib-multiselect
      [options]="options"
      [value]="selected"
      placeholder="Select items…"
      [searchable]="true"
      [showSelectAll]="true"
      (valueChange)="selected = $event">
    </pui-lib-multiselect>
  `
})
export class MyComponent {
  options: MultiSelectOption[] = [
    { value: 'a', label: 'Alpha' },
    { value: 'b', label: 'Beta', group: 'Greek' },
  ];
  selected: (string | number)[] = [];
}
Use a ref to pass arrays — HTML attributes accept JSON strings only.
import { useRef, useEffect, useState } from 'react';
import '@bhairab-patra/platform-ui';

function MyComponent() {
  const ref = useRef(null);
  const [selected, setSelected] = useState([]);

  useEffect(() => {
    if (ref.current) {
      ref.current.options = [
        { value: 'a', label: 'Alpha' },
        { value: 'b', label: 'Beta' },
      ];
    }
  }, []);

  return (
    <pui-lib-multiselect
      ref={ref}
      placeholder="Select items…"
      onValueChange={e => setSelected(e.detail)}
    />
  );
}
Assign array properties via JS after customElements.whenDefined.
<pui-lib-multiselect id="ms" placeholder="Select items…" searchable show-select-all></pui-lib-multiselect>

<script>
customElements.whenDefined('pui-lib-multiselect').then(() => {
  const el = document.getElementById('ms');
  el.options = [
    { value: 'a', label: 'Alpha' },
    { value: 'b', label: 'Beta' },
  ];
  el.addEventListener('valueChange', e => console.log(e.detail));
});
</script>
