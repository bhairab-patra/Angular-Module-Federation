Framework Usage

pui-lib-tabs is a Web Component — works in Angular, React, and plain HTML. Pass the tabs array as a JS property from React/HTML; Angular uses [tabs] binding. Content projected inside <pui-lib-tabs> renders as the panel area — you control what shows based on the active tab.
