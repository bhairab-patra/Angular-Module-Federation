Basic

Pass an array of BreadcrumbItem objects. The last item is the active page — rendered bold with a subtle tint background.

Items with Icons

Each BreadcrumbItem accepts an optional icon SVG string — rendered inline before the label using the platform icon size.

Framework Usage

pui-lib-breadcrumb accepts an items array via Angular property binding or as a JS property after element upgrade.
