Basic Label

Just text — nothing else on by default.

Required Field

[required]="true" adds a red asterisk after the text. This is purely visual — wire your own form validation separately.

Info Icon & Tooltip

showInfo is off by default — the info icon only renders when you explicitly turn it on and supply info text. Hover the icon below to see the tooltip.

Tooltip Position

infoPosition controls which side the tooltip bubble opens on — pick whichever won't get clipped by your layout.

Paired With a Field

Every pui-lib-* form control already accepts its own label input for the common case. Reach for pui-lib-label instead when you need the info tooltip, or when you're labelling something that isn't a single platform-ui component (a custom field, a group of radio buttons, a third-party widget).

Framework Usage

pui-lib-label is a small presentational component — no form logic, no value binding. Place it directly above (or beside) whatever it labels; it doesn't create an implicit <label for> association, so pair it visually rather than relying on click-to-focus behaviour.
