Framework Usage

pui-lib-radio-group is a Web Component — works in Angular, React, and plain HTML with no extra config. The options array must be passed as a JS property — assign el.options = [...] after mount, or pass a JSON string attribute. Angular uses [options] binding natively.

Use [(ngModel)]. Pass a typed [options] array directly — no JSON serialization needed.
Set options as a JS property via ref. Listen to valueChange CustomEvent for selection changes.
