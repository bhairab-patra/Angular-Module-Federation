Default Variant

Card-style panels separated by a gap. Good for FAQ lists and content pages.

Bordered Variant

Single outer border with internal dividers. Compact and settings-panel appropriate.

Ghost Variant

No borders or backgrounds — just text and a hover state. Best for sidebar navigation or inline help.

With Icons

Add an icon property to any item using a key from the Platform UI icon registry (e.g. 'settings', 'bell', 'user').

Multiple Open Simultaneously

By default only one panel can be open. Set [allowMultiple]="true" to allow any number.
