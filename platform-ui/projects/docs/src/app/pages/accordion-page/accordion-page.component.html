Default Variant — With Icons

Card-style panels separated by a gap. The open row's header tints with the brand-light token and its icon becomes a solid brand chip. Good for FAQ lists and content pages.

Default Variant — Without Icons

Omit icon on each item and the badge column disappears automatically.

Bordered Variant — With Icons

Single outer border with internal dividers. Icon renders as a circular tinted badge. Add a subtitle to show a permanent teaser line under the title. Compact and settings-panel appropriate.

Bordered Variant — Without Icons

Same flat settings-list layout, no icon badge column.

Multiple Open Simultaneously

By default only one panel can be open. Set [allowMultiple]="true" to allow any number.

Framework Usage

pui-lib-accordion is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. items and openIds are objects/arrays, so set them as JS properties (not HTML attributes); variant and allowMultiple work as plain attributes; events are standard DOM CustomEvents.
