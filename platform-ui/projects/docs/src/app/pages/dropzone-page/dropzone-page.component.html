Upload States

The file list reflects whatever status/progress you set on each DropzoneFile as your own upload logic runs — done, uploading (with a progress bar), and error are all shown here at once.

Framework Usage

pui-lib-dropzone is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. files is an array, so set it as a JS property (not an HTML attribute); the component never uploads anything itself — listen for filesAdded and drive your own upload call, updating each file's status/progress as it runs.
