Framework Usage

pui-lib-footer is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. noticeSlides and links are arrays, so set them as JS properties (not HTML attributes); variant and text props work as plain attributes; events are standard DOM CustomEvents.
