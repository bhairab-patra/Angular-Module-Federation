Built-in Validation Rules

Common per-character rules built right into the component — no hand-written regex needed for these. Each one shows its own combined error message after blur (try typing below), and also registers as a real Angular Validator, so formControlName sees the exact same errors in form.get('x').errors.

Framework Usage

pui-lib-input is a Web Component — works in Angular, React, and plain HTML with no extra config. String inputs work as HTML attributes. Booleans (disabled, readonly, clearable, showCount) accept "true" strings or JS properties. maxLength accepts a number or numeric string.
