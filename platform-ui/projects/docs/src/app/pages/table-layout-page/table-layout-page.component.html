Configuration Reference

Every option used in this template, and what it does.

sortableClick a column header to sort by it.
searchableAdds the search box in the toolbar; filters client-side across all columns.
selectableAdds a checkbox column with select-all in the header.
paginated + pageSizeSplits rows into pages of the given size.
stickyHeaderKeeps the column headers visible while the body scrolls.
stripedAlternating row background for readability.
maxHeightCaps the table's height in pixels — the body scrolls internally past that.
actionsPer-row 3-dot menu; each action can be conditionally disabled per row.
column type: 'currency' / 'date' / 'badge' / 'pills'Built-in cell formatting — no custom template needed.
