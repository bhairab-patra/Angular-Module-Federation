Solifi Portal — Four-Section Configuration

The header is built from four independent sections — Logo, Heading, Search, and Avatar — each toggled on/off with showLogo / showHeading / showSearch / showUser. Avatar has two styles: avatarMode="menu" (name + email + dropdown) or avatarMode="plain" (round chip only, no menu). An optional Hamburger button (showHamburger) can also be shown before the logo, for toggling your own app sidebar — its open/close animation is driven by hamburgerOpen and it emits (hamburgerToggle) on click.

Framework Usage

pui-lib-header is a Web Component — it works in Angular, React, and plain HTML with no extra wrappers. String inputs are HTML attributes; objects/arrays accept a JSON string or a JS property; events are standard DOM CustomEvents.
