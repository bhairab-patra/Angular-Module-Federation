Basic

Bind [total], [page], and [pageSize]. Listen to (pageChange) to update. The component never mutates page itself.

Page Size Selector

[showPageSizeSelector]="true" (default) adds a per-page dropdown. Listen to (pageSizeChange) to reload with the new size.

Page: {{ sizePage }} · Per page: {{ sizePerPage }}

Without First / Last Buttons

Set [showFirstLast]="false" for simpler contexts like table footers.

Compact Mode

[compact]="true" hides the info text and page-size selector, reduces button size. Ideal for modal footers or tight spaces.

Large Range with Ellipsis

When total pages exceed [maxVisible] (default 7), middle pages collapse with an ellipsis. The active page always stays visible with its neighbours.

Page {{ largePage }} of 100

Empty State

When [total]="0", the info text reads "No items" and all navigation is disabled.
