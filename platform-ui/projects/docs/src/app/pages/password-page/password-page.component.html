Validation Rules Checklist

Enable showRules to display a live checklist while the field is focused. Combine with requireUpper, requireNumber, and requireSpecial.

Copy to Clipboard

Enable copyable to show a clipboard button beside the eye toggle. The icon turns green after a successful copy.

Try revealing then copying the pre-filled value.

States

Disabled locks the input. The error prop adds a red border and shows a message; hint shows helper text.

Reactive Forms (formControlName)

pui-lib-password-input implements ControlValueAccessor, so it drops directly into a FormGroup with formControlName, with no manual [value]/(valueChange) wiring needed. Its minLength, requireUpper, requireNumber, and requireSpecial rules are also registered as a real NG_VALIDATORS validator, so they show up automatically in form.get('password').errors.passwordStrength.

Framework Usage

pui-lib-password-input is a self-contained Web Component. All string and boolean attributes work from HTML. For reactive form integration in Angular, bind with (valueChange) or, since the component implements ControlValueAccessor, with formControlName directly.
