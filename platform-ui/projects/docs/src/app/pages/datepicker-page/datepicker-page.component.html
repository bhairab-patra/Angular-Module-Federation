Framework Usage

pui-lib-datepicker works in Angular, React, and plain HTML. Pass value as a JS Date from Angular; use an ISO string from React/HTML. Listen to (valueChange) (single) or (rangeChange) (range) for selection events. It also implements ControlValueAccessor, so in Angular you can bind it with formControlName instead of manual [value]/(valueChange).
