Framework Usage

pui-lib-search is a Web Component — drop it in any framework. Simple inputs (strings, numbers, booleans) work as HTML attributes. Arrays (suggestions, recentSearches) work as a JSON string attribute or as a JS property via ref.

Use Angular template binding — arrays bind directly with [suggestions].
Pass arrays as a JSON string attribute or set them via ref in useEffect.
