Grouped vs flat navigation — navGroups vs navItems

The groups input accepts two shapes. Pass an array of SolifiNavGroup objects (each with its own id, label, and items) to get a section label above every cluster — that's what "navGroups" means. If you don't want section labels at all, skip the group wrapper and pass a plain SolifiNavItem[] array instead — commonly called "navItems". The sidebar checks whether the first array element has an items key: if it doesn't, the whole array is treated as one flat, ungrouped list and no label is rendered above it. Same [groups] input either way — nothing else in your template changes.
