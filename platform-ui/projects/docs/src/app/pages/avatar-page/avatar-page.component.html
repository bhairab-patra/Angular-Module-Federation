User Menu Card

Click the card to open the dropdown. The chevron rotates from › to ⌃. menuItems accepts an optional iconName (platform icon registry), danger for destructive actions, and dividerBefore to insert a separator.

menuAction emitted: {{ lastAction }}

Collapsed

Set [collapsed]="true" to render only the avatar chip — for a collapsed sidebar rail. The dropdown still opens on click.

Photo Avatar

Pass avatarUrl and the chip switches from a rounded-square initials tile to a circular photo.

Sizes

Three chip sizes — sm 32px, md 40px (default), lg 48px.

Without a Menu

When menuItems is empty, the card is static — no chevron, not clickable.

Framework Usage

pui-lib-avatar is a standalone Web Component. Use (menuAction) in Angular; listen to the menuAction custom event in React and plain HTML.
